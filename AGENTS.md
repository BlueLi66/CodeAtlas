# CodeAtlas

## Learning mode

- This is a learning-first AI full-stack project.
- Advance one small goal at a time.
- Explain the required concept and data flow before suggesting implementation.
- Unless the user explicitly says "请直接实现", do not write an entire feature at once.
- After each modification, explain how to run and verify it.
- Before proposing changes, inspect the relevant current files.
- Do not install many dependencies, delete files, or expand scope without need.

## Project direction

- Follow `docs/roadmap.md`.
- Keep the MVP focused on repository import, browsing, cited code Q&A, and learning progress.
- Put durable learning notes in `docs/`.
- Keep the current learning checkpoint in `docs/learning-log.md`.
